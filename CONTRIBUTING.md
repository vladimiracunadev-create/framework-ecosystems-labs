# Contribuir

1. Define concepto, destino de producto y contrato afectado.
2. Verifica documentación oficial y fecha.
3. Usa `templates/FRAMEWORK_TEMPLATE.md` o `templates/LESSON_TEMPLATE.md`.
4. Conserva semántica y pruebas comunes.
5. Usa pnpm para todo el ecosistema JavaScript/TypeScript.
6. Ejecuta `pnpm check` o los comandos sin dependencias del README.
7. No incluyas secretos, artefactos generados, métricas inventadas ni código copiado sin licencia.

Una ficha de catálogo no debe presentarse como soporte completo.
