# Laboratorio 06 — Comparación frontend

Implementa la misma pantalla TaskFlow con dos ecosistemas entre React, Angular, Vue y Svelte.

## Contrato visual

- encabezado “Mis tareas”;
- estado vacío comprensible;
- formulario con etiqueta visible;
- título obligatorio y máximo 120;
- envío mediante teclado;
- indicador de espera;
- error recuperable;
- lista semántica;
- foco anunciado tras éxito o error.
