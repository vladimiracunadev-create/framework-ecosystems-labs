# Laboratorio 04 — Spring Boot adapter

Fragmento vertical para observar aplicación autónoma, controlador, tipos y convenciones JVM. Requiere Java 21 y Maven compatible con la versión declarada.

```bash
cd labs/04-spring-boot
./mvnw spring-boot:run
```

El ZIP no incluye el wrapper binario. Si no existe, usa un Maven instalado o genera el wrapper siguiendo la documentación oficial. El ejercicio debe extraer servicio, errores estables, idempotencia y pruebas de contrato.
