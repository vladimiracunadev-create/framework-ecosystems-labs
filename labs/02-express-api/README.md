# Laboratorio 02 — Express adapter

Adaptador pedagógico del contrato TaskFlow sobre Express. Permite comparar cuánto código de transporte desaparece y qué responsabilidades siguen perteneciendo a la aplicación.

```bash
pnpm --filter @labs/express-api install
pnpm --filter @labs/express-api start
```

Pendientes deliberados para el estudiante: extraer dominio, agregar pruebas de contrato externas, persistencia, cierre, métricas y autorización. No es una plantilla productiva.
