# Laboratorio 05 — ASP.NET Core Minimal API

Fragmento vertical para comparar minimal APIs, tipado y composición .NET. Requiere SDK .NET 10.

```bash
dotnet run --project labs/05-aspnet-core/TaskFlow.csproj
```

El reto es extraer servicios, normalizar errores, agregar pruebas de contrato y comparar una Minimal API con controladores.
